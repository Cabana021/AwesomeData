# AwesomeData

Projeto com foco em prática para análise e engenharia de dados. 

> Automações em Python para simular rotinas operacionais e transformar dados em análises úteis.

## Cases disponíveis

| Prévia | Case |
|--------|------|
| <img src="assets/exemplos/funil_comercial/receita-ytd-2026-x-2025.png" width="320" alt="Gráfico de linhas com a receita mensal de 2026 e de 2025"> | **[Funil comercial](src/analises/comercial/funil_comercial/README.md)**<br><br>Simula os negócios de um funil comercial B2B, compara janeiro a setembro de 2026 com 2025 e gera sete gráficos para mostrar onde o comercial perde receita e o que esperar do Q4.<br><br>[Ler o storytelling](src/analises/comercial/funil_comercial/STORYTELLING.md) |

## Contribuição

Achou a iniciativa interessante? Sinta-se à vontade para contribuir! 

Contribuições são bem-vindas.

Fluxo sugerido:

1. Faça um fork do projeto.
2. Crie sua branch (`git checkout -b feature/minha-feature`).
3. Faça commits claros e pequenos.
4. Rode testes e checks locais.
5. Abra um Pull Request.
