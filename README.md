# AwesomeData

Projeto com foco em prática para análise e engenharia de dados. 

> Automações em Python para simular rotinas operacionais e transformar dados em análises úteis.

## Case disponível

### [Ranking de produtos](src/analises/comercial/ranking_produtos/README.md)

Simula venda semanal, consolida os resultados em uma planilha Excel e gera quatro gráficos para acompanhar vendas, faturamento e metas.
